# sha256sum

## What it does
Computes and verifies SHA-256 checksums for files.

## Options
- `-b`: read in binary mode
- `-c`: check checksums from a file
- `-h`, `--help`: show help text
- `-V`, `--version`: show version information

## UNIX origin
A Unix/Linux checksum utility from the GNU toolchain lineage rather than one specific historical Unix release.
