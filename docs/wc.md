# wc

## What it does
Counts lines, words, and characters in input.

## Options
- `-l`: count lines
- `-w`: count words
- `-c`: count bytes or characters
- `-m`: count characters
- `-h`, `--help`: show help text
- `-V`, `--version`: show version information

## UNIX origin
A classic Unix text-processing utility from early BSD and System V releases.
