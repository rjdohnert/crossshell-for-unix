# tail

## What it does
Prints the last part of a file or input stream.

## Options
- `-n N`: show the last `N` lines
- `-f`: follow the file as it grows
- `-c N`: show the last `N` bytes
- `-h`, `--help`: show help text
- `-V`, `--version`: show version information

## UNIX origin
A classic Unix text-display utility from early BSD and System V releases.
