# getfacl

## What it does
Provides a baseline `getfacl` command that prints Windows ACL information in a POSIX-like text format.

## Options
- `-R`: recurse into directories
- `-h`, `--help`: show help text
- `-V`, `--version`: show version information

## UNIX origin
A POSIX ACL inspection utility used to review access-control entries for files and directories.
