# test

## What it does
Evaluates a condition and returns a success or failure status.

## Options
- `-f file`: check whether a file exists and is a regular file
- `-d dir`: check whether a directory exists
- `-e path`: check whether a path exists
- `-h`, `--help`: show help text
- `-V`, `--version`: show version information

## UNIX origin
A core shell utility from POSIX-compatible Unix systems.
