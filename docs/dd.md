# dd

## What it does
Copies and converts data at the byte level between files, devices, or streams.

## Options
- `if=file`: read input from `file`
- `of=file`: write output to `file`
- `bs=BYTES`: set the block size
- `count=N`: copy only `N` blocks
- `conv=...`: specify conversion options
- `-h`, `--help`: show help text
- `-V`, `--version`: show version information

## UNIX origin
A classic Unix data-copy utility from early BSD and System V systems.
