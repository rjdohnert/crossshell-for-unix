# csplit

## What it does
Splits a file into smaller files based on context lines or patterns.

## Options
- `-f prefix`: use a prefix for output files
- `-n digits`: use a fixed number of digits in suffixes
- `-s`: suppress file size messages
- `-h`, `--help`: show help text
- `-V`, `--version`: show version information

## UNIX origin
A classic Unix file-splitting utility from the System V era.
