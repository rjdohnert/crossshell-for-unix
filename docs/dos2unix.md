# dos2unix

## What it does
Converts text files between DOS/Windows line endings and Unix line endings.

## Options
- `-k`, `--keepdate`: preserve timestamps
- `-o`, `--to-stdout`: write output to standard output
- `-v`, `--verbose`: show conversion details
- `-h`, `--help`: show help text
- `-V`, `--version`: show version information

## UNIX origin
A Unix-oriented text-conversion utility rather than a native core command from a single historic Unix release.
