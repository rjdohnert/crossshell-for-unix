# split

## What it does
Splits a file into multiple smaller files.

## Options
- `-l N`: split by `N` lines
- `-b N`: split by `N` bytes
- `-a suffix_length`: set the suffix length
- `-h`, `--help`: show help text
- `-V`, `--version`: show version information

## UNIX origin
A classic Unix file-splitting utility from early BSD and System V releases.
