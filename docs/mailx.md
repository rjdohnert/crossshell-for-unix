# mailx

## What it does
Sends email via SMTP.

## Usage
`mailx [OPTIONS] recipient...`

## Options
- `-s SUBJECT`: subject
- `-r FROM`: sender address (required)
- `-R REPLYTO`: reply-to address
- `-S SERVER[:PORT]`: SMTP server and optional port (default `localhost:25`)
- `-u USER`: SMTP username
- `-p PASSWORD`: SMTP password
- `--ssl`: enable SSL/TLS
- `--html`: treat body as HTML
- `-c ADDR`: CC recipient (repeatable)
- `-b ADDR`: BCC recipient (repeatable)
- `-a FILE`: attachment path (repeatable)
- `-m TEXT`: message body
- `-f FILE`: read message body from file
- `-H NAME:VALUE`: add custom header (repeatable)
- `-t MS`: SMTP timeout in milliseconds
- `-n`: dry-run mode (compose and validate, no send)
- `-v`: verbose logging
- `--help`: show help text
- `--version`: show version information

## Notes
This implementation sends mail through a PowerShell/.NET SMTP flow using a temporary JSON payload and sender script generated by `mailx`.
If `-m` and `-f` are both omitted, the message body is read from standard input.

## UNIX origin
`mailx`-style command-line mail workflow.
