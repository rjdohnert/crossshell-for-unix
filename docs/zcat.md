# zcat

## What it does
Decompresses one or more `.gz` files and writes their content to standard output.

## Options
- `-h`, `--help`: show help text
- `--version`: show version information

## Notes
- Baseline implementation supports gzip files from local paths.
- This command is intended for pipe-friendly text workflows.

## UNIX origin
`zcat` is a classic Unix utility that displays compressed file content without permanently extracting files.
