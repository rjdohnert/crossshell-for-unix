# lex

## What it does
Generates lexical analyzers from input specifications.

## Options
- `-o file`: write the generated C scanner to `file`
- `-t`: write scanner to standard output
- `-h`, `--help`: show help text
- `-V`, `--version`: show version information

## UNIX origin
A classic Unix tool from the GNU and BSD toolchain ecosystem, commonly used on System V-like systems.
