# basename

## What it does
Removes any leading directory components from a pathname and prints the final path component.

## Options
- `-a`, `--multiple`: process multiple arguments
- `-s`, `--suffix`: remove a trailing suffix
- `-z`, `--zero`: use NUL as the line terminator
- `-h`, `--help`: show help text
- `-V`, `--version`: show version information

## UNIX origin
A standard Unix pathname utility that appeared in early BSD and System V toolsets.
