# cbasic

## What it does
Runs BASIC source files through a BASIC interpreter compatible with MS-BASIC command set.

## Options
- `-h`, `--help`: show help text
- `-V`, `--version`: show version information
- script file path: run the specified BASIC program

## UNIX origin
Not a standard Unix command from a specific release; it is a compatibility-style interpreter rather than a native historic Unix utility.
