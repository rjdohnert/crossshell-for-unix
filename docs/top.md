# top

## What it does
Displays a live, continuously refreshed view of running processes and system CPU/memory usage.

## Options
- `-d`, `--delay <seconds>`: set refresh delay in seconds (default `1.0`)
- `-i <seconds>`: set refresh delay in seconds (default `1.0`)
- `-n <rows>`: number of process rows to display (default `20`)
- `-s <mode>`: sort mode: `cpu`, `mem`, `pid`, or `name`
- Help: press `h` or `?` while the live display is running

## Interactive keys
- `q`: quit live view
- `Esc`: quit live view
- `Ctrl+X`: quit live view

## UNIX origin
A classic Unix process-monitoring utility from the BSD and System V lineage.
