# diff3

## What it does
Compares three files and shows the differences among them.

## Options
- `-E`: ignore whitespace differences
- `-m`: merge output format
- `-L label`: label a file in the output
- `-h`, `--help`: show help text
- `-V`, `--version`: show version information

## UNIX origin
A standard Unix three-way comparison utility common in BSD and System V environments.
