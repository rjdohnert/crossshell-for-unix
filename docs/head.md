# head

## What it does
Prints the first part of a file or input stream.

## Options
- `-n N`: print the first `N` lines
- `-c N`: print the first `N` bytes
- `-q`: suppress headers when printing multiple files
- `-h`, `--help`: show help text
- `-V`, `--version`: show version information

## UNIX origin
A classic Unix text-display utility from early BSD and System V releases.
