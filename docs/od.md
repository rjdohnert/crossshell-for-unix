# od

## What it does
Dumps files in octal, decimal, or hexadecimal formats.

## Options
- `-A radix`: specify the address base
- `-t type`: specify the output format
- `-v`: print all data
- `-h`, `--help`: show help text
- `-V`, `--version`: show version information

## UNIX origin
A classic Unix file-dumping utility from early BSD and System V releases.
