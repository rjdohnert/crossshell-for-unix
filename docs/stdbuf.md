# stdbuf

## What it does
Modifies the buffering behavior of a command’s standard streams.

## Options
- `-i0`, `-o0`, `-e0`: set unbuffered mode
- `-e0`: set stderr to unbuffered mode
- `-h`, `--help`: show help text
- `-V`, `--version`: show version information

## UNIX origin
A Unix/Linux utility from the GNU toolchain lineage rather than a single historic Unix release.
