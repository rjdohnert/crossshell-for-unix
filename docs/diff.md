# diff

## What it does
Compares two files or directories and reports differences.

## Options
- `-u`: unified diff format
- `-a`: treat all files as text
- `-r`: recurse into directories
- `-q`: report only whether files differ
- `-h`, `--help`: show help text
- `-V`, `--version`: show version information

## UNIX origin
A classic Unix file-comparison utility from early BSD and System V systems.
