# uname

## What it does
Prints system information such as the operating system name and kernel release.

## Options
- `-a`: print all system information
- `-s`: print the operating system name
- `-r`: print the kernel release
- `-m`: print the machine hardware name
- `-n`: print the node name
- `-h`, `--help`: show help text
- `-V`, `--version`: show version information

## UNIX origin
A standard Unix system-information utility from early BSD and System V releases.
