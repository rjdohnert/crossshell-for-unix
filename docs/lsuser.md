# lsuser

## What it does
Lists local user accounts with selected attributes such as account name, UID, shell, groups, and login time.

## Options
- `-a`, `--attributes ATTRS`: select which attributes to display
- `-h`, `--help`: show help text
- `-V`, `--version`: show version information

## UNIX origin
A Unix-style account-listing utility inspired by IBM AIX `lsuser` rather than a single classic BSD/System V command.
