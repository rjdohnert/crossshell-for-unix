# cut

## What it does
Removes fields or columns from each line of a file or input stream.

## Options
- `-b list`: select only certain bytes
- `-c list`: select only certain characters
- `-f list`: select only certain fields
- `-d delim`: use a delimiter for fields
- `-s`: suppress lines without delimiters
- `-h`, `--help`: show help text
- `-V`, `--version`: show version information

## UNIX origin
A standard Unix text-processing utility from early BSD and System V releases.
