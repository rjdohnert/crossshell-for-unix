# comm

## What it does
Compares two sorted files line by line and shows which lines are unique to each file or common to both.

## Options
- `-1`: suppress lines unique to the first file
- `-2`: suppress lines unique to the second file
- `-3`: suppress lines common to both files
- `-h`, `--help`: show help text
- `-V`, `--version`: show version information

## UNIX origin
A classic Unix text-comparison utility from the BSD and System V toolsets.
