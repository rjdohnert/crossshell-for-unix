# cpio

## What it does
Archives and extracts files into and from cpio archives.

## Options
- `-i`: copy in (extract)
- `-o`: copy out (create)
- `-p`: copy files to another directory
- `-h`, `--help`: show help text
- `-V`, `--version`: show version information

## UNIX origin
A classic Unix archive utility from the System V and BSD eras.
