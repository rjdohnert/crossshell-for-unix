# id

## What it does
Displays the effective user and group IDs and associated group memberships.

## Options
- `-u`: print only the user ID
- `-g`: print only the group ID
- `-n`: print names instead of numeric IDs
- `-h`, `--help`: show help text
- `-V`, `--version`: show version information

## UNIX origin
A standard Unix account-information utility from early BSD and System V releases.
